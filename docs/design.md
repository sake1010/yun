# 匿名聊天室 畫面設計

這份文件記錄第一輪畫面設計的結果,供下一步做前端時使用。畫面「有哪些元素、各自的行為」以 [architecture.md](architecture.md) 第 7 節為準;這份文件負責補上它刻意不規定的部分:**外觀、尺寸、各狀態長什麼樣子**。

設計畫布(可以直接看畫面):https://claude.ai/artifact/KAgNUi8Gvkx2oGKmjXRrxS
這個連結是私人的,只有建立者能開。

---

## 1. 設計方向

- **手機優先**,電腦版是同一套視覺的寬版。
- 安靜、乾淨的青綠色調,沒有頭像,靠「代號顏色」和「左右位置」區分人。
- **淺色與深色兩套**,依裝置設定自動切換(架構文件的決定)。畫布上用「外觀」開關切換是為了方便預覽,正式網頁**不放切換按鈕**。
- 所有可點的東西至少 44 × 44 px(手機觸控)。
- 沒有 emoji 當圖示,圖示一律是線條風格的 SVG,線寬 2。
- 提示不單靠顏色:錯誤一定有文字,收回、斷線等都有圖示加文字。

> 風格是我自己定的(使用者的風格欄位當時沒有填),想換風格時,**只改下面第 2、3 節的設計代號(token)**,元件尺寸與版面不必動。

## 2. 色彩

用「設計代號」(token)命名,前端實作時做成 CSS 變數,淺色與深色各一組。

| 代號 | 用途 | 淺色 | 深色 |
| --- | --- | --- | --- |
| `bg` | 整個畫面背景 | `#F3F6F8` | `#0E1418` |
| `surface` | 頂欄、輸入區、對方的訊息泡泡、卡片 | `#FFFFFF` | `#172028` |
| `surface2` | 示範條、載入骨架、圖片佔位、選中項目 | `#E8EEF2` | `#212C35` |
| `text` | 主要文字 | `#17212B` | `#E6EDF2` |
| `muted` | 次要文字(時間、提示、說明) | `#56626E` | `#9AA8B4` |
| `line` | 邊框與分隔線 | `#C9D2DA` | `#2E3B47` |
| `accent` | 主按鈕、連結、強調 | `#0B7480` | `#4CC9D4` |
| `accent-ink` | 主按鈕上的文字 | `#FFFFFF` | `#06262A` |
| `mine` | 自己的訊息泡泡 | `#0B7480` | `#116069` |
| `mine-ink` | 自己泡泡上的文字 | `#FFFFFF` | `#FFFFFF` |
| `warn` | 錯誤、斷線、收回按鈕的文字與強調 | `#A8201A` | `#FFB4AB` |
| `warn-bg` | 錯誤提示的底色 | `#FCE9E7` | `#3B1F1D` |

深色模式的 `line` 在代號輸入頁畫布上用了 `#33414D`,和聊天室的 `#2E3B47` 略有不同,實作時統一用 `#2E3B47`。

### 代號顏色

每個代號依字串算出固定的一個顏色(六選一),同一個代號永遠同色。**顏色不存資料庫,由前端計算。** 淺色用較深的色、深色用較亮的色,確保在背景上對比足夠。

| 代號色 | 淺色 | 深色 |
| --- | --- | --- |
| 1 紅 | `#B3261E` | `#FF8A80` |
| 2 琥珀 | `#8A5A00` | `#F2B94B` |
| 3 綠 | `#1B7F3B` | `#5FD38A` |
| 4 藍 | `#1F5FBF` | `#7CAEFF` |
| 5 紫 | `#8E3FBF` | `#C79BFF` |
| 6 粉紅 | `#B0306E` | `#FF8FC0` |

線上名單前面的小圓點(表示在線)固定用第 3 色(綠)。

## 3. 字型與尺寸

**字型**:Noto Sans TC(Google Fonts),後備依序為 Noto Sans SC、Noto Sans KR、Noto Sans JP、系統字型。這樣五種語言都有合適的字。字重用 400、500、700、800。

| 用在哪裡 | 字級 | 字重 |
| --- | --- | --- |
| 代號頁主標題 | 30 px | 800 |
| 對話框標題、電腦版聊天室標題 | 20 px | 800 |
| 內文、訊息 | 15 px | 400 |
| 輸入框 | 16–17 px(16 以上可避免 iPhone 在點輸入框時自動放大畫面) | 400 |
| 代號、按鈕文字 | 15–17 px | 700 |
| 代號與時間那一行 | 13 px(時間 12 px) | 代號 700 |
| 進出提示、說明文字 | 13 px | 400 |

**圓角**:輸入框與按鈕 12–14 px;訊息泡泡 18 px,其中「訊息的尾角」是 6 px(對方的左上、自己的右下);對話框 20 px;全圓角的膠囊按鈕(新訊息按鈕)。

## 5. 畫面清單與畫布對照

畫布上 11 個畫面。標號對應架構文件第 7 節。

| 畫布畫面 | 對應 | 內容 |
| --- | --- | --- |
| 代號輸入頁 | 7.1 | 一般狀態 |
| 代號被占用與連線失敗 | 7.1 | 錯誤狀態 |
| 語言選單展開 | 7.1、7.2 | 五種語言列表 |
| 聊天室(手機) | 7.2 | 一般畫面 |
| 線上名單展開、斷線、送太快 | 7.2 | 三種狀態合併成一張 |
| 收回確認 | 7.2 | 確認對話框 |
| 圖片放大檢視 | 7.3 | 全螢幕檢視 |
| 載入中 | 7.2 | 剛進來載入歷史訊息 |
| 沒有歷史訊息 | 7.2 | 空狀態 |
| 示範控制面板 | 7.5 | 階段一專用 |
| 聊天室(電腦)與分頁標題 | 7.2、7.4 | 含瀏覽器分頁列範例 |

### 5.1 代號輸入頁
由上而下:語言按鈕(右上)→ 圖示 → 標題「匿名聊天室」→ 一句說明 → 「你的代號」標籤 → 輸入框 → 提示列 → 進入按鈕。

- **一般狀態**:輸入框空白時,「進入聊天室」按鈕是灰淡(停用)。提示列左邊是說明「代號永久屬於這個瀏覽器,別人不能用。」,右邊是字數「0 / 12」。
- **代號被占用**:輸入框邊框變 `warn` 色;提示列左邊換成紅字加圖示「這個代號有人在用了,請換一個。」,按鈕可按。
- **連線失敗**:表單下方出現一張 `warn-bg` 底色的卡片,有斷線圖示、「無法連到伺服器」「請檢查網路後再試一次。」和「重試」按鈕。
- 格式不合(太長、含看不見字元等)的提示沿用「被占用」的版型,只換文字。

### 5.2 聊天室頂欄
- **手機**:左邊是一個大按鈕——人群圖示加兩行字,第一行「線上 N 人」(粗體),第二行是代號清單(自己標「(你)」),放不下就用刪節號。點了展開名單。右邊是語言按鈕(只有地球圖示)。
- **電腦**:左邊「匿名聊天室」,右邊語言按鈕(地球圖示加語言名稱加箭頭)。線上名單固定在右側欄。

### 5.3 訊息區的各種項目
| 項目 | 樣子 |
| --- | --- |
| 他人文字訊息 | 靠左。上方一行:代號(粗體、代號色)加時間(灰、小字)。下方泡泡:`surface` 底加邊框,左上角是小圓角 |
| 自己的文字訊息 | 靠右。上方一行:時間加代號(代號色)。泡泡:`mine` 底、白字,右下角是小圓角。泡泡下方有一個灰色底線小字「收回」 |
| 網址 | 在泡泡內,`accent` 色加底線,在新分頁開啟。自己的泡泡內網址同樣顯示 |
| 圖片 | 圓角方塊,點一下進入放大檢視。目前畫布用灰色方塊加圖示加文字「圖片・點一下放大」代表 |
| 檔案 | 圓角卡片:檔案圖示、檔名(粗體,可換行)、大小(灰小字)、右邊一個 44 × 44 的下載按鈕 |
| 已收回 | 置中、灰色斜體小字「某某 收回了一則訊息」 |
| 進出提示 | 置中、灰色小字「某某 進來了」「某某 離開了」 |
| 新訊息按鈕 | 右下角漂浮的膠囊按鈕:`accent` 底、向下箭頭加「有 N 則新訊息」,帶陰影 |
| 正在輸入 | 輸入區上方一列:三個漸淡的圓點加文字「小華、小美 正在輸入…」 |

訊息之間垂直間距 12 px(電腦 14 px)。

### 5.4 輸入區
左邊附加按鈕(迴紋針)、中間輸入框(單行起始、可成長為多行)、右邊送出鈕(紙飛機)。

- 內容為空時,送出鈕停用(變淡)。
- 被「送太快」限制時,送出鈕停用,且「正在輸入」列的位置改顯示 `warn` 色的「送太快了,請稍等」加時鐘圖示。
- 電腦版輸入框下方一行小字:「Enter 送出・Shift + Enter 換行」。手機版沒有這行。

### 5.5 線上名單
- **手機**:點頂欄展開成一張浮動的卡片,蓋在訊息區上(訊息區變暗),標題「線上 N 人」加關閉鈕,下面每一人一列:綠色小圓點、代號(代號色、粗體)。自己後面有灰色的「(你)」。
- **電腦**:右側欄,同樣的列表,最上方是人群圖示加「線上 N 人」。

### 5.6 連線橫幅
訊息區上方一條通欄橫幅,`warn-bg` 底、`warn` 色粗體字,左邊轉圈圖示,文字「連線中斷,重新連線中…」。恢復後消失。

### 5.7 收回確認對話框
整個畫面變暗,中間一張圓角卡片:標題「收回這則訊息?」、說明「收回後,所有人只會看到『已收回』,原本的內容無法復原。」、兩個等寬按鈕「取消」(白底框線)與「收回」(`warn` 底)。

### 5.8 圖片放大檢視
黑底全螢幕(不分淺色深色)。上方左邊關閉鈕、中間顯示發送者代號與時間;中間是圖片;下方一個寬按鈕「下載原圖(檔案大小)」。

### 5.9 載入中與空狀態
- **載入中**:頂欄人數顯示「線上 …」;訊息區中間一行轉圈圖示加「正在載入歷史訊息…」,下面是五個灰色骨架泡泡(左右交錯);送出鈕停用。
- **空狀態**:訊息區正中間一個圓角圖示、「還沒有人說話」、「來打個招呼吧!」;底部只有一行「某某 進來了」。

### 5.10 語言選單
按鈕展開成一張浮動列表,五個選項各 48 px 高,選中的有底色與勾勾:繁體中文、简体中文、English、한국어、日本語。每個選項標註自己語言的 `lang`,確保字型正確。

### 5.11 分頁標題(電腦版畫布最上方)
瀏覽器分頁列範例,分頁名稱「(3) 匿名聊天室」。這不是網頁的一部分,是示範有未讀時標題長什麼樣子。

### 5.12 示範控制面板(僅階段一)
360 px 寬的面板,標題「示範控制面板」加「僅示範模式」標籤。分三組:
- 連線:模擬斷線、恢復連線
- 觸發提示:模擬檔案太大(超過 5 MB)、模擬代號被占用、模擬送太快
- 假的聊天對象:開關「自動說話、進來與離開」

所有聊天室畫面最上方有一條 28 px 的細條「示範模式・對話對象為模擬」,階段二要移除。

## 6. 行為補充

設計時決定的細節,前端實作要照做:

- 輸入框在手機版 Enter 是換行;電腦版 Enter 送出、Shift + Enter 換行。
- 「收回」按鈕只出現在自己的訊息上;按下後先出現確認對話框。
- 點頂欄的線上摘要展開名單,再點一次或點關閉鈕收合;展開時下方訊息區變暗。
- 所有互動元件用真正的按鈕或連結,可用鍵盤操作;只有圖示的按鈕有文字標籤(給螢幕閱讀器)。
- 錯誤提示、斷線橫幅設為會被螢幕閱讀器立即朗讀的提示區域。
- 介面文字依語言切換;代號與訊息內容保持原樣。五種語言的文字長度不同,**按鈕與標籤要能容納最長的語言**(英文和韓文通常比中文、日文長),不可寫死寬度。

## 7. 設計目前還沒涵蓋的

下一步做前端時需要補,或做的時候再決定:

- **檔案太大**的提示放在哪、長什麼樣:只在示範面板有觸發按鈕,畫布上沒有實際的提示畫面。建議沿用「送太快」的版型(輸入區上方一行 `warn` 色文字)。
- **圖片與檔案上傳中**的進度,以及**上傳失敗**的樣子:沒有設計。
- **代號登記中**(按下進入後等待回應)的按鈕狀態:沒有設計。建議按鈕文字變「登記中…」並停用。
- **圖片載入失敗**或簽名網址過期的樣子:沒有設計。
- **電腦版線上名單**人很多時的捲動、**手機版摘要**放不下時的刪節方式:只有簡單的處理,沒有針對很多人的畫面。
- **電腦版**的新訊息按鈕與其他狀態(載入中、空狀態、斷線、送太快):電腦版只畫了一般畫面,其他狀態沿用手機版的做法放進主欄即可。
- 圖片、示範對話內容、示範用的代號(阿森、小華、Amy、阿傑、小美)都是佔位,不是正式文案。
